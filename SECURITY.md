# Security policy

ROMcraft Fieldnotes is independent educational documentation. A failed flash or compromised ROM can cause permanent data loss or privacy harms. Any device-specific procedure must be validated against the actual model, bootloader revision, and firmware.

## Reporting

Please open a GitHub issue for publicly safe corrections (incorrect commands, broken source links, unsupported devices). For private reports involving security flaws, use GitHub's private vulnerability reporting facility if enabled in the repository, or ask the repository maintainer for a secure disclosure channel. Do **not** paste exploit details, EFS images, IMEIs, serial numbers, tokens, account credentials or unredacted logs into public issues.

This repository does not contain firmware or ROM binaries and offers no official support for third-party operating systems. External links are references, not endorsements.
